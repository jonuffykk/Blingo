# Notas de atualização

## [2.2.0] - 2026-11-20

- Pip, Dot, Moxie, Pebble e Echo falam, celebram, encorajam e comemoram no fim das atividades que conduzem. A galeria permite rever a celebração dos personagens encontrados.
- O modo offline mantém os arquivos de cada endereço do Blingo em seu próprio cache, inclusive quando uma nova versão é instalada.
- O GitHub Actions publica executáveis portáteis para Windows x64 e ARM64 com notas de atualização e hashes SHA-256. A demo web usa a Vercel.

## [2.1.0] - 2026-11-20

- Trilha de inglês para brasileiros com 16 lições, 96 exercícios, revisão espaçada e instruções em português.
- Três vozes de inglês americano com reprodução offline, em velocidade normal ou lenta.
- Perfis locais, corações, XP, metas, sequência de estudo e backup de progresso.

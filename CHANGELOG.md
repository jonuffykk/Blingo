# Notas de atualização

## [2.2.0] - 2026-11-20

- Pip, Dot, Moxie, Pebble e Echo falam, celebram, encorajam e comemoram no fim das atividades que conduzem. A galeria permite rever a celebração dos personagens encontrados.
- O modo offline mantém os arquivos de cada endereço do Blingo em seu próprio cache, inclusive quando uma nova versão é instalada.
- O GitHub Actions verifica o build, atualiza o GitHub Pages e publica novas versões com executáveis portáteis para Windows x64 e ARM64, ZIP web e checksums SHA-256.
